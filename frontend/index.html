How It Works

System pipeline and architecture

01

Voice Input

Browser captures your microphone and converts speech to text using the Web Speech API — no external service or cost.

02

Security Guards

Your query passes through Input Guard (jailbreak detection) and Topic Guard (college-only filter) before reaching the AI.

03

AI Processing

Fine-tuned LLaMA 3.1 running via Ollama processes your query with live database context injected into the prompt.

04

Voice Response

AI response is spoken back using the browser's Text-to-Speech engine — natural, clear, and instant.

05

OTP Verification

For personal data like fees or attendance, the system verifies your identity via OTP before sharing any information.

06

Ticket System

Unresolved issues auto-convert to support tickets, visible in the admin dashboard for staff action.
